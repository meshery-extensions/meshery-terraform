# Meshery Terraform

Terraform and OpenTofu integration for [Meshery](https://meshery.io) and Kanvas.

This repository is in the **proposal stage**. The architecture deep dive, proposed decisions (ADRs), a prototype provider-schema converter, and measured scale findings are under review in the open pull request titled "Proposal: Terraform/OpenTofu integration for Meshery and Kanvas". Nothing here is a supported product yet.

## Status

- Proposal under review. See the open pull requests and issues labeled `decision-needed`.
